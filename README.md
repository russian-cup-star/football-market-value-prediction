# Анализ и прогнозирование рыночной стоимости футболистов

Проект по дисциплине «Теория работы с открытыми данными».

## О проекте

Цель - проанализировать факторы, влияющие на рыночную стоимость футболистов
(возраст, позиция, статистика, уровень чемпионата, гражданство), и построить
модель машинного обучения, предсказывающую примерную стоимость игрока.

## Источник данных

Данные взяты с Kaggle: [Football Data from Transfermarkt](https://www.kaggle.com/datasets/davidcariboo/player-scores?resource=download).

Используемые таблицы:
- `players.csv` - базовая информация об игроках (возраст, позиция, гражданство, клуб).
- `player_valuations.csv` - история рыночных стоимостей игроков.
- `appearances.csv` - статистика матчей (голы, передачи, минуты, карточки).
- `clubs.csv` - справочник клубов.
- `competitions.csv` - справочник турниров/лиг.

Тяжёлые CSV-файлы не хранятся в репозитории. Чтобы воспроизвести проект, скачайте датасет по ссылке выше и положите файлы в `data/raw/`.

## Ключевые выводы EDA

1. Распределение стоимости - сильно скошено вправо: большинство игроков
   дешевле 1 млн €, дороже 25 млн € - единицы.
2. Возраст - нелинейная зависимость: пик стоимости в 22–27 лет, спад
   после 30.
3. Позиция - атакующие игроки дороже оборонительных.
4. Голы и передачи - положительная, но умеренная связь.
5. Лига - топ-5 лиг дороже остальных; при анализе нужно разделять
   популярность в базе (число игроков) и уровень лиги (медианная стоимость).
6. Гражданство - связано с ценой.
7. Корреляции - сильнее всего `minutes_played`, `appearances`, `goals`.

## Предобработка признаков

- Целевая переменная: `log1p(market_value_in_eur)` — лог-преобразование
  из-за сильной скошенности распределения цены.
- Признаки (8 числовых + категориальные):
  - Числовые: `age`, `height_in_cm`, `goals`, `assists`, `appearances`,
    `minutes_played`, `yellow_cards`, `red_cards`.
  - Категориальные: `position`, `sub_position`, `country_of_citizenship`,
    `league_label` (топ-15 категорий + `Other`).
- Исключено: `highest_market_value_in_eur`,
  `market_value_in_eur` (целевая).
- Масштабирование: `StandardScaler` только для числовых, `fit` только
  на train.
- Split: 80/20, `random_state=42`.

Артефакты: `X_train.csv`, `X_test.csv`, `y_train.csv`, `y_test.csv`,
`scaler.pkl`, `feature_names.pkl`, `num_features.pkl`.
